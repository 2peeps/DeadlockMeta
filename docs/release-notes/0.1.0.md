Первая тестовая версия.

**Скачать:** файл `DeadlockMeta-0.1.0.zip` ниже → распаковать → запустить `DeadlockMeta.exe`.
Устанавливать ничего не нужно. В Deadlock включи режим «Окно без рамки».

Что внутри:
- таблица винрейтов всех героев (высокие ранги / все ранги, 7 / 14 / 30 дней);
- оверлей на экране выбора героя: наводишь курсор на карточку — видишь винрейт.

Проверено на 1920×1080. Если на твоём разрешении что-то не так — открой Issue и приложи `data\log.txt` и скриншот экрана выбора героя.

Windows может предупредить, что программа не подписана: «Подробнее» → «Выполнить в любом случае».
