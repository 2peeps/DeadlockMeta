# Deadlock Meta

Актуальный винрейт героев Deadlock — в отдельном окне и прямо в игре, на экране выбора героя.

![Сборки героя](docs/screenshot-builds.png)

![Оверлей в игре](docs/screenshot-overlay.png)

## Что умеет

- **Таблица героев**: винрейт, доля матчей с героем и число игр с сортировкой по любому столбцу. Ранг выбирается над таблицей: все ранги или от Emissary до Eternus.
- **Сборки и предметы**: нажми на героя в таблице — выедет панель с тремя лучшими сборками игроков (по винрейту в реальных матчах, с копированием ID) и лучшими предметами для начала, середины и конца игры.
- **Автообновление**: когда выходит новая версия, в окне появляется кнопка «Обновить».
- **Оверлей**: на экране выбора героя и на экране «Создать состав» наводишь курсор на карточку — сверху, рядом с заголовком экрана, появляется плашка с винрейтом. Зелёный — 50% и выше, красный — ниже.
- **Прицелы**: почти 100 форм прицелов (больше 1000 вариантов с цветами) с фильтрами по форме и цвету, цвет выбирается кружками прямо на карточке, свои прицелы в редакторе с живым превью и вставка кода из игры, с сайтов с прицелами или от друга. Кнопка «Поставить» записывает прицел в настройки игры, а если игра потом его сбросит (например, после патча), программа вернёт его сама. Каталог лежит в [crosshairs/catalog.json](crosshairs/catalog.json) и подтягивается без выпуска новой версии.
- **Настройки** (шестерёнка вверху): период статистики (7, 14 или 30 дней), включение оверлея, поведение прицела.

Статистика берётся из открытого API сообщества [deadlock-api.com](https://deadlock-api.com) и обновляется автоматически.

## Установка

1. Скачай архив со страницы [Releases](../../releases) и распакуй куда угодно.
2. Запусти `DeadlockMeta.exe`. Если Windows покажет окно «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае» (программа не подписана).
3. В Deadlock включи режим «Окно без рамки» (Настройки → Видео).
4. Открой экран выбора героя и наведи курсор на героя.

Устанавливать .NET не нужно — всё внутри exe. Нужна Windows 10 или 11 (64-бит).

Подробная инструкция лежит в архиве (`ИНСТРУКЦИЯ.txt`) и в [docs/INSTRUCTION_RU.txt](docs/INSTRUCTION_RU.txt).

## Как это работает и безопасно ли

Программа не читает память игры и не внедряется в процесс. Для плашки она делает снимки экрана, как программа для записи видео, сравнивает карточки героев с их портретами и рисует своё прозрачное окно поверх. Гарантий от Valve нет, но это тот же класс программ, что и обычные оверлеи.

Единственный файл игры, который программа меняет, — файл настроек `Steam\userdata\<аккаунт>\1422450\remote\cfg\citadel_hero_settings.lst`, и только строки прицела. Это те же настройки, что меняются в меню игры. Запись идёт только при закрытой игре, а перед каждой записью копия файла сохраняется в `data\backups`.

Что известно на сейчас:

- проверено на 1920×1080; на других разрешениях сетка героев ищется автоматически, но это ещё не тестировалось;
- работает только в режиме «Окно без рамки»;
- если Valve перерисует экран выбора героя, распознавание придётся обновить.

## Если не работает

Пришли файл `data\log.txt` (Настройки → «Открыть папку с логом»), скриншот экрана выбора героя и разрешение монитора — через [Issues](../../issues).

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
.\publish.ps1
```

Скрипт собирает `app\DeadlockMeta.exe` и архив `release\DeadlockMeta-<версия>.zip`.

| Папка | Что внутри |
|---|---|
| `Core\` | распознавание карточек, захват экрана, загрузка статистики, слежение за игрой |
| `MainWindow.xaml`, `OverlayWindow.cs` | главное окно и плашка поверх игры |
| `tests\e2e.ps1` | проверка оверлея на сохранённом скриншоте, без игры (нужен второй монитор) |
| `Core\Crosshair*.cs`, `CrosshairService.cs`, `MainWindow.Crosshairs.cs` | прицелы: коды, файл настроек игры, каталог, вкладка |
| `tools\make-crosshairs.ps1` | собирает `crosshairs\catalog.json` из списка форм и цветов |
| `server\` | сервер счётчиков популярности и прицелов от игроков (Cloudflare Workers), см. его README |

`DeadlockMeta.exe --selftest-crosshairs` прогоняет все прицелы каталога через все форматы кодов и проверяет запись настроек на копии файла игры (результат в `data\crosshair_selftest.txt`).
| `tests\robustness.ps1` | повреждённый кэш, нет интернета, папка без прав записи, вторая копия программы |
| `DeadlockMeta.exe --selftest-builds [rank=N]` | загружает сборки и предметы для всех героев, итог в `data\selftest.txt` |
| `DeadlockMeta.exe --test <скриншот> <высота>` | распознавание сетки героев на картинке, итог в `data\test_result.txt` |
| `tools\make-icon.ps1` | генерация иконки |
