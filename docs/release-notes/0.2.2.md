**Надёжность**

- Если распаковать программу в папку без прав записи (например, Program Files), она больше не падает при запуске, а хранит данные в `%LOCALAPPDATA%\DeadlockMeta`.
- Повреждённый кэш (сбой питания, ответ прокси вместо данных) больше не ломает загрузку: программа скачивает данные заново.
- Если быстро переключать период или ранг в настройках, последнее изменение больше не теряется.
- Панель сборок показывает три сборки, даже если одна из них удалена или не загрузилась.
- Обновление проверяет контрольную сумму архива с GitHub перед установкой.

**Оверлей**

- Поддержка мониторов 16:10 и 4:3: экран выбора героя ищется и при масштабировании интерфейса по ширине. Проверено на снимках 720p, 900p, 1080p, 1440p, 4K, 21:9, 16:10 и 4:3.

Если у тебя 0.2.0 или 0.2.1 — нажми «Обновить» вверху окна программы.
