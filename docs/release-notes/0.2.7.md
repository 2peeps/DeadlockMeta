**Плашка для героев с высоким приоритетом**

На экране «Создать состав» карточки героев с высоким приоритетом игра рисует наклонёнными и чуть крупнее — из-за этого программа их не узнавала, и плашка с винрейтом не появлялась. Теперь такие карточки распознаются (проверено на ваших скриншотах: Graves, Seven, Grey Talon).

Также экран выбора/состава теперь надёжнее определяется, когда курсор при входе уже стоит на карточке в верхних рядах.

Обновление: кнопка «Обновить» вверху окна программы.
