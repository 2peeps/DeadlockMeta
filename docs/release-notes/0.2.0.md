**Что нового**

- **Сборки и предметы на героя.** Нажми на героя в таблице — справа выедет панель:
  - 3 лучшие сборки игроков из игрового каталога, по одной на экране (листай стрелками ‹ › или клавишами ← →). Порядок — по винрейту в реальных матчах с поправкой на число игр. Кнопка «Копировать ID сборки».
  - лучшие предметы для начала, середины и конца игры с винрейтом. Наведи на иконку — увидишь название и цену.
- **Автообновление.** Программа сама проверяет новые версии. Когда выйдет обновление, вверху окна появится кнопка «Обновить до …» — она скачает новую версию и перезапустит программу.

Эту версию нужно один раз скачать вручную (в 0.1.0 автообновления ещё не было): скачай `DeadlockMeta-0.2.0.zip` ниже и замени старый `DeadlockMeta.exe` новым. Дальше обновления будут приходить сами.
