**Исправление**

- Сборки в панели героя иногда показывались не те: ID сборки уникален только внутри одного героя (например, 262104 — это и сборка Haze, и сборка Dynamo), а программа брала первую попавшуюся. Теперь сборка берётся строго для выбранного героя и совпадает с тем, что находит игра по этому ID.
- Рядом с ID теперь видна версия сборки — как в игре.

Если у тебя 0.2.0 — просто нажми кнопку «Обновить» вверху окна программы.
